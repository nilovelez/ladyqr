# Status

LadyQR is a privacy-oriented QR code generator and URL shortener. Milestones 0 to 5 are done. The generator works and is verified, there is a public website with a live demo at https://ladyqr.nilovelez.com/, the OVH hosting has been tested (see `docs/hosting.md`), and the editor is published on the author's own domain, https://1qr.es/. The admin (M3), the short links (M4) and the installer (M5) are built and tested locally, and not yet published on 1qr.es. Since M5 the site works and is secure without .htaccess: short links live in ladyqr-data.php and index.php answers them, the configuration is a file of LADYQR_ constants, and every visit goes to a four-screen installer until LadyQR is installed. M6 is under way: the release zip is built by a GitHub Action with a permanent ladyqr-latest.zip link, INSTALL.txt is written, and the installer got fixes from Nilo's first real install of a test zip on 1qr.es. Next: a new icon that works at small sizes, a design review, the README with a Troubleshooting section, and the 1.0.0 release. `CLAUDE.md` and `docs/HANDOFF.md` hold what a new session needs; the roadmap is in `docs/PLAN.md`.
