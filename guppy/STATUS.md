# Status

LadyQR is a privacy-oriented QR code generator with an optional link shortener. Milestones 0 to 6 are done and 1.0.0, the first release, is published on GitHub: a zip with the generator, the admin, short links served by PHP from ladyqr-data.php (case-insensitive), and a four-screen web installer, plus INSTALL.txt and a README with Troubleshooting. Its zip, ladyqr-latest.zip, is attached to the release and always reachable at https://github.com/nilovelez/ladyqr/releases/latest/download/ladyqr-latest.zip. Nilo runs it on https://1qr.es/, the website and demo are at https://ladyqr.nilovelez.com/. M7 is done and published as 1.1.0, with its zip attached to the release; CHANGELOG.md, in the repository only, lists each version's notable changes. M7 brought automated tests in tests/ (node --test, with throwaway sites on PHP's built-in server instead of Apache), the encoder's numeric and alphanumeric modes (picked automatically), and a QR icon on each short link in the admin that opens the generator through #text=, with the optional LADYQR_QR_BASE. The website was then redesigned: the hero is a welcome with the ladybug and the real editor embedded, and there is a new section on the link shortener with a screenshot of the admin. Next: Nilo's fixes to the website, then his call from the backlog: nginx and LiteSpeed, or customizing the generator page. `CLAUDE.md` and `docs/HANDOFF.md` hold what a new session needs; the roadmap is in `docs/PLAN.md`.
