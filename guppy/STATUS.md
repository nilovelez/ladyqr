# Status

LadyQR is a privacy-oriented QR code generator and URL shortener. Milestone 0 is done and merged: the generator (own encoder, PNG and SVG, settings, warnings, dark mode, English and Spanish) works and is verified. The public website and a live demo are at https://ladyqr.nilovelez.com/. Next is milestone 1, testing the target hosting. Publishing on the author's own domain waits for that.
